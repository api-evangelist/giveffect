# Giveffect

> Giveffect is an all-in-one nonprofit management platform combining ten connected systems — CRM, online fundraising and donation processing, peer-to-peer and event fundraising, volunteer management, membership management, marketing communications, wealth screening and major-gifts tools, website building, and smart automation. An optional "open API" is available only on the enterprise (Ultimate+) tier for integrating platform data with external systems. Giveffect publishes no developer portal, no API reference, no OpenAPI specification, no SDKs and no MCP server; API access is provisioned per customer by sales.

> This file is generated by API Evangelist from public sources. Giveffect does not publish an llms.txt of its own (https://www.giveffect.com/llms.txt returns 404).

## APIs

- [Giveffect API (enterprise / Ultimate+ only)](https://www.giveffect.com/pricing): Programmatic access to platform data — donors, donations, volunteers, campaigns, events. Base host https://api.giveffect.com. The host is live and answers JSON; the root returns `{"status":{"code":200,"message":"OK - Systems operational"}}` and every unknown path returns `{"error":{"code":404,"message":"Not Found - Invalid resource"}}`. Every response carries an `X-Request-Id` correlation uuid. No machine-readable contract is published.

## How to get access

- The API is a plan feature, not a self-serve product. The Ultimate tier reads "All system features (excludes open API)"; only Ultimate+ reads "Open API and custom integration".
- [Pricing](https://www.giveffect.com/pricing): three tiers — Lite (10k–30k records, up to 10 users), Ultimate (30k–100k records, up to 20 users), Ultimate+ (100k–millions of records, unlimited users). No prices are published; every tier reads "Contact us".
- [Schedule a Call](https://www.giveffect.com/schedule-a-call): the only route to API access.
- A 14-day free trial of the platform is offered after a demo ([FAQ](https://www.giveffect.com/faq)).
- https://www.giveffect.com/api redirects (302) to https://www.giveffect.com/signin — the API area is behind the customer login.

## What is NOT published

- No OpenAPI / Swagger / GraphQL / AsyncAPI contract on any Giveffect host.
- No developer portal — developers.giveffect.com and docs.giveffect.com return HTTP 200 but render Giveffect's "Error 404" page.
- No SDKs or client libraries in npm, PyPI, RubyGems, Packagist or crates.io. The GitHub account github.com/Giveffect has zero public repositories.
- No MCP server, no A2A agent card, no /.well-known/* documents, no llms.txt, no security.txt.
- No published rate limits, no error reference, no versioning or deprecation policy, no SLA, no status page (status.giveffect.com is a soft 404).
- No API changelog. Product updates are published as a blog tag.
