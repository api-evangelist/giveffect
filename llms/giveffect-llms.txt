# Giveffect

> Giveffect is an all-in-one nonprofit management platform combining ten connected systems — CRM, online fundraising and donation processing, peer-to-peer and event fundraising, volunteer management, membership management, marketing communications, wealth screening and major-gifts tools, website building, and automation. An optional "open API" is available on the enterprise (Ultimate+) tier for integrating platform data with external systems. Public API documentation and an OpenAPI specification are not published; API access is provisioned to enterprise customers.

## APIs

- [Giveffect API (enterprise / Ultimate+)](https://www.giveffect.com/pricing): Programmatic access to donors, donations, volunteers, campaigns, and events. Base host: https://api.giveffect.com
